# ✦ NovaKitap E-Ticaret Platformu

NovaKitap, kitaplar, kırtasiye ürünleri ve oyuncakların satıldığı, modern, kullanıcı dostu ve ölçeklenebilir bir ASP.NET Core MVC projesidir.

## 🚀 Proje Özellikleri
- **Çift Tema Desteği:** Karanlık ve Aydınlık mod seçenekleri.
- **Kapsamlı Profil Yönetimi:** Telefon, adres, kart bilgileri yönetimi ve favori ürünler.
- **Sipariş Yönetimi:** Aktif ve geçmiş siparişlerin takibi.
- **Akıllı Admin Paneli:** Sipariş durumlarını AJAX ile güncelleyebilme ve kargo animasyonları.
- **Nova Asistan:** Kullanıcıların kitap arama ve sipariş takibi yapabildiği dahili sohbet botu.

## 🛠 Kullanılan Teknolojiler
- **Backend:** ASP.NET Core MVC (C#)
- **Veritabanı:** MS SQL Server (Entity Framework Core)
- **Frontend:** Bootstrap, JavaScript (Fetch API, AJAX)
- **Sürüm Kontrol:** Git & GitHub
